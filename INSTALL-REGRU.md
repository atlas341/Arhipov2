# Инструкция по установке формы на Reg.ru

Сайт — статика (HTML/CSS/JS) + один PHP-обработчик формы. Reg.ru shared-хостинг поддерживает PHP без настроек, всё заработает «из коробки».

## Что заливать на хостинг

В корень публичной папки (обычно `/public_html/`):

```
public_html/
├── index.html
├── products.html
├── privacy.html
├── send.php          ← обработчик формы (новый)
├── config.php        ← настройки почты (новый, отредактировать!)
├── .htaccess         ← защита config.php
└── assets/
    └── (всё как раньше)
```

После заливки **обязательно** открой `config.php` через файловый менеджер Reg.ru и поправь:

```php
'to'        => 'info@tdarhipov.ru',       // куда приходят заявки
'from'      => 'noreply@tdarhipov.ru',    // обратный адрес
'from_name' => 'Сайт ТД Архипов',
'use_smtp'  => false,                     // см. ниже выбор режима
```

## Выбор режима отправки

### Режим A — `use_smtp => false` (рекомендую начать с этого)

Использует встроенную PHP-функцию `mail()`. Работает, **если почта `info@tdarhipov.ru` создана на том же Reg.ru-хостинге** (через их панель «Почта»).

**Что сделать:**
1. В панели Reg.ru создай ящик `info@tdarhipov.ru` и `noreply@tdarhipov.ru` (второй — для From, чтобы письма выглядели от сайта).
2. В `config.php` оставь `'use_smtp' => false`.
3. Залей файлы — готово. **Никаких библиотек ставить не нужно.**

### Режим Б — `use_smtp => true`

Нужен, если **почта на стороннем сервисе** (Яндекс.Почта для бизнеса, Mail.ru для бизнеса, Gmail).

**Что сделать:**

1. В почтовом ящике, с которого будем отправлять, **создай «пароль приложения»**. Обычный пароль использовать нельзя.
   - **Яндекс**: `id.yandex.ru/security` → «Пароли приложений» → «Почта»
   - **Mail.ru**: `account.mail.ru/user/2-step-auth/passwords/` → создать новый
   - **Gmail**: `myaccount.google.com/apppasswords` (нужна двухфакторка)

2. Скачай **PHPMailer** с GitHub:
   - Открой https://github.com/PHPMailer/PHPMailer/releases
   - Скачай последний `.zip` (он маленький, ~100 КБ)
   - Распакуй, переименуй папку в `phpmailer`
   - Залей в корень сайта — должно получиться: `public_html/phpmailer/src/PHPMailer.php`

3. В `config.php` выстави:
   ```php
   'use_smtp'    => true,
   'smtp_host'   => 'smtp.yandex.ru',          // или smtp.mail.ru / smtp.gmail.com
   'smtp_port'   => 465,                       // для Gmail — 587
   'smtp_user'   => 'info@tdarhipov.ru',       // полный адрес ящика
   'smtp_pass'   => 'xxxxxxxxxxxxxxxx',        // тот самый пароль приложения
   'smtp_secure' => 'ssl',                     // для Gmail — 'tls'
   ```

## Что в письме приходит

При каждой заявке тебе на `info@tdarhipov.ru` падает HTML-письмо с шапкой ТД Архипов и таблицей всех полей формы. Внизу — **блок «Проверка контрагента по ИНН»** с шестью кнопками-ссылками:

- 🔍 **ФНС ЕГРЮЛ/ЕГРИП** — открывается сразу с подставленным ИНН, показывает статус, реквизиты, адрес, ОКВЭД
- 📊 **Прозрачный бизнес ФНС** — налоговые задолженности, штрафы, недостоверность сведений
- 💰 **Финансовая отчётность ФНС** — баланс, выручка, прибыль за последние годы
- ⚖️ **Арбитражные дела** — kad.arbitr.ru, нужно ввести ИНН вручную
- 👮 **ФССП** — исполнительные производства, долги у приставов
- 🎯 **Контур.Фокус** — сводная карточка с рисками (бесплатный просмотр)

Менеджер открывает письмо и одним кликом смотрит нужный источник. Всё бесплатно, всё из официальных реестров, всё **актуально на момент клика**.

## Защита от ботов и спама

Сделано:

- **Honeypot-поле** `<input name="website">` — скрыто от людей через position: -9999px, бот его заполняет и его заявка молча отбрасывается.
- **Rate limit** — не более 3 заявок в минуту с одного IP.
- **Валидация на сервере** — ИНН должен быть 10 или 12 цифр, телефон не короче 6 символов, согласие на ПД обязательно.
- **Очистка ввода** — все поля проходят `trim` + ограничение длины, чтобы никто не залил гигабайт данных.

При желании можно добавить **Google reCAPTCHA v3** — невидимая, не раздражает пользователей. Если поток заявок маленький — пока не нужно.

## Как протестировать что работает

1. Открой свой сайт.
2. Заполни форму — ИНН для теста: `7707083893` (это реальный ИНН Сбербанка, для проверки рисуется красивый блок ссылок).
3. Поставь галочку, нажми «Отправить заявку».
4. Должна появиться зелёная плашка «Спасибо! Заявка принята.»
5. Проверь почту `info@tdarhipov.ru` — там должно быть письмо.

Если что-то не пришло:
- Загляни в файл `form-log.txt` в корне сайта — там лог последних отправок с пометкой `ok=YES/NO` и текстом ошибки.
- Проверь папку «Спам» в почте.

## Куда смотреть если форма не работает

| Симптом | Где смотреть |
|---|---|
| «Не удалось отправить» в браузере | `form-log.txt` в корне — там причина |
| Пишет «PHPMailer не установлен» | Проверь, что `phpmailer/src/PHPMailer.php` существует |
| Письма уходят в спам | Настрой SPF/DKIM-записи домена в DNS (Reg.ru делает по инструкции из их саппорта) |
| mail() вернула false | На хостинге не настроена локальная отправка — переключайся на SMTP (`use_smtp => true`) |

## После запуска

- Проверь `form-log.txt` раз в неделю — там видно сколько было заявок и сколько провалилось.
- Если придёт много спама через форму — добавь reCAPTCHA, скажу как.
